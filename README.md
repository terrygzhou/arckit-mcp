# arckit-mcp

Standalone ArcKit MCP server — exposes the ArcKit architecture-governance harness
as MCP tools so an AI agent can inspect projects, check gate tiers, walk handoff
chains, and persist artefacts without leaving the session.

## Package layout

```
arckit_mcp/
    __init__.py
    __main__.py
    _registry.py   # generated by scripts/generate-mcp-registry.py
    gates.py       # generated by scripts/generate-mcp-gates.py
    handoffs.py    # generated by scripts/generate-mcp-handoffs.py
    server.py      # MCP server entry point
    sync.py        # regenerate generated files from an installed ArcKit
tests/
    mcp/
        conftest.py
        test_gates.py
        test_next_step.py
        test_seed_context.py
        test_sync.py
```

## Dev loop

```bash
# Install the package (editable) into the shared venv
cd ~/.local/share/arckit-mcp && source .venv/bin/activate
pip install -e ~/projects/arckit-mcp

# Run the test suite
cd ~/projects/arckit-mcp
python -m pytest tests/ -v

# Regenerate _registry.py / gates.py / handoffs.py from the installed
# ArcKit source tree (requires `arckit` to be installed, or pass --source-root)
arckit-mcp-sync
arckit-mcp-sync --source-root ~/projects/arc-kit

# Boot-test the MCP server
arckit-mcp
```

## Generators

The three generated files are produced by scripts that live in the
`arc-kit` repo (`scripts/generate-mcp-{registry,gates,handoffs}.py`).
Those scripts default to writing into this repo's `arckit_mcp/` directory
(sibling layout) and accept `ARCKIT_MCP_ROOT` env var or a CLI arg to
override the output path.

`arckit-mcp-sync` (in `arckit_mcp/sync.py`) is the convenience wrapper that
runs all three generators with the correct local output paths.

## Installation

```bash
pip install ~/projects/arckit-mcp
# or
pip install ~/projects/arckit-mcp[dev]   # includes arckit + pytest
```
